How the classifier works

1. Dataset: Loads labelled messages from the UCI SMS Spam Collection.

2. Preprocessing: Converts text to lowercase, normalizes accents, removes English stop words, and creates unigram/bigram TF-IDF features.

3. Training: Trains a Multinomial Naive Bayes model on 80% of the labelled messages.

4. Evaluation: Calculates accuracy and a confusion matrix from the held-out 20% test set.

5. Prediction: Applies the same fitted TF-IDF + Naive Bayes pipeline to the message entered above.

Dataset: Almeida & Hidalgo, UCI SMS Spam Collection (2011), CC BY 4.0. This is an educational demonstration, not a production email security filter.
